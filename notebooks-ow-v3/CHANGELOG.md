# OW v3 change record

## 2026-11-10 implementation revision

This revision follows the OW v2 architecture audit and preserves the original
student initialization rule: ImageNet B7 plus newly initialized study modules.
Existing pseudo-mask files are reused without alteration. Legacy teacher weights
are not loaded into the new students.

### Supervision and numerical fixes

- Real authenticity labels now supply zero manipulation targets in memory.
- Empty Fake pseudo masks are unavailable localization targets, while classification
  training continues for those images.
- A binary valid canvas mask excludes letterbox pixels from segmentation loss and
  localization metrics and follows geometric augmentation exactly.
- Real images receive full valid-pixel BCE. Retained nonempty Fake images receive
  an explicit BCE/foreground-Dice average. An all-Real batch avoids the ineffective
  empty-target Dice penalty. Spectral transforms and sensitive loss reductions
  remain float32 under AMP.
- Optional Train/Validation `seg_quality_csv` flags can reject externally assessed
  Fake masks. Nonempty area is not interpreted as confidence.
- Fake teacher agreement and Real positive-mask behavior are reported separately.

### Separately named architecture candidates

- Added a nonlinear residual fusion MLP with a direct RGB classifier path. Its final
  output layer starts at zero, preserving initial RGB predictions.
- Added average-plus-max evidence pooling, per-color SRM residuals, and local
  three-band RGB FFT power maps. Local FFT excludes outer letterbox padding using
  explicit geometry, then applies patch centering and a Hann taper.
- Added separable ASPP/decoder blocks with GroupNorm. The theoretical 8.7× reduction
  applies to two decoder convolution blocks, not the entire model or wall-clock time.
- Kept corrected early fusion and additive late fusion as v3-trained references.
- Added stepwise component experiments rather than attributing any future combined
  gain to every change independently.

### Training and evaluation

- Added named backbone/head AdamW groups, a 0.1 backbone LR multiplier, frozen B7
  BN running statistics with trainable affine weights, and 5% update warmup followed
  by cosine decay. These are recorded starting settings shared by the variants.
- Checkpoints preserve optimizer/scaler/scheduler/RNG state and partial-epoch
  statistics at optimizer update boundaries, including accumulation tails.
- Added source digests to the data/training protocol guard and strict checkpoint
  architecture loading. Old implementation, source, and smoke/full mismatches fail.
- Smoke runs evaluate Validation only. Full runs select by Validation accuracy and
  defer Test until all three planned epochs complete.
- Best-checkpoint evaluation is independent of the training-resume flag. A fresh
  run refuses to reuse a working directory containing checkpoints.
- Added model-only inference timing and peak allocated CUDA-memory reporting, with
  explicit batch size, precision, warmup, repeat count, and preprocessing exclusion.

### Notebook and app delivery

- Added one CPU Train/Validation mask audit, ten self-contained training notebooks,
  and one matched four-core-model final comparison notebook.
- The source files and notebooks are regenerated by `make_ow_v3_notebooks.py`.
- The app recognizes `ow_v3` architecture metadata and supplies exact valid-canvas
  masks for local-frequency models in ordinary and streaming inference. v2 and
  legacy checkpoint dispatch are retained.
- Added model, loss, optimizer/scheduler, checkpoint, app geometry, and notebook
  integration checks. Test execution evidence belongs in the publication/run record.

### Interpretation and outstanding evidence

The documentation records pseudo-label semantics and the draft's selection-metric
and architecture-description differences. Draft DOCX files were not edited by this
revision. Final mask correctness, mixed-face crop labels, split independence,
held-out accuracy gains, and real deployment performance remain empirical checks.
The implementation does not establish that VERITAS outperforms B7.

Development branch: `codex/ow-v3-improvements`. See [the publication record](PUBLICATION.md)
for verified GitHub/Kaggle links, passed GPU smoke checks, the final-data mask audit,
and the submitted full-data runs. No final three-epoch accuracy claim is available.
